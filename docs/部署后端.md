# 后端部署（WSL + Tomcat）

## 编译 WAR

```bash
cd /d/Projects/project/Blog/Blog
mvn clean package -DskipTests
```

输出：`target/ROOT.war`

## 部署到 Tomcat

```bash
# 直接复制（WSL root 可免密）
wsl -d Ubuntu-22.04 --user root bash -c "cp /mnt/d/Projects/project/Blog/Blog/target/ROOT.war /volume/Blog/tomcat/webapps/ROOT.war"
```

Tomcat 会自动解压并重新加载，无需重启。

## 验证

```bash
curl -s -X POST http://localhost:18016/api/auth/ping
# → {"code":1,"message":"success","data":"local_only_token"}
```

## 手动部署

如果 WSL 命令不行，直接打开 `\\wsl.localhost\Ubuntu-22.04\volume\Blog\tomcat\webapps\` 目录，替换 `ROOT.war` 文件。

# 部署前端

```
docker build -t blog-next .  

 docker compose -f //wsl.localhost/Ubuntu-22.04/volume/Blog/bg-com.yml up -d bg-blog    
```

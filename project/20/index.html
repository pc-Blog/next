EduMark

> **AI 驱动的智能教育批改平台** | FastAPI + Vue 3 + MySQL + Qdrant + Celery --- ## 1. 项目概述 EduMark 是一套面向中小学教育的智能作业批改系统。系统利用**阿里云 OCR**、**百炼视觉模型（Qwen-VL）** 和**大语言模型（Qwen-Plus）**，实现了从作业图像上传、题目自动识别到 AI 智能批改的全流程自动化。 ### 设计目标 - **减轻教师负担**：自动化批改重复性作业，让教师聚焦教学本身 - **即时反馈**：学生提交作业后秒级获得批改结果与错题分析 - **知识增强**：基于 RAG（检索增强生成）技术，结合教学知识库提升批改准确性 - **双引擎灵活切换**：支持阿里云 OCR 和百炼视觉模型两种识别模式 --- ## 2. 核心功能 ### 2.1 作业批改 ![作业批改完整数据流向图.png](/data/media/216.png) 作业批改是系统的核心功能，支持以下能力： - **多方式图片采集**：支持文件上传（拖拽/点击）和摄像头实时拍摄两种模式 - **批量上传**：一次可提交多张作业图片，系统自动处理 - **图像预处理增强**：自动进行对比度（1.2x）和锐度（1.1x）增强，提升识别准确率（可在配置中关闭） - **双识别引擎**： - **阿里云 OCR 模式**：先通过 `RecognizeEduPaperCut` 切题定位每道题的区域，再通过 `RecognizeEduQuestionOcr` 识别题目内容与学生答案，支持题型自动检测（选择题/填空题/计算题/解答题等） - **百炼视觉模型模式**：端到端图像理解，直接由视觉模型（Qwen-VL 系列）识别所有题目及其答案，支持跨页题目合并 - **AI 大模型批改**：调用百炼 Qwen-Plus 对每道题进行评分（满分 10 分），输出得分、批改结果（正确/错误/部分正确）、评语和解题分析 - **RAG 知识增强**：批改时自动检索向量知识库中的相关知识片段，注入 Prompt 辅助评分，提升准确率 - **异步处理**：通过 Celery 后台异步执行批改任务，前端轮询查询进度 ![image20.png](/data/media/217.png) ![image21.png](/data/media/218.png) ![image22.png](/data/media/219.png) ### 2.2 知识库管理（RAG） ![image23.png](/data/media/220.png) - **多格式支持**：上传 PDF、Word、PPT 等格式的教学文档 - **全自动解析**：文档上传后自动触发 Celery 异步解析流程 - 通过 **MinerU** 服务解析文档结构 - 提取文本内容，按 2000 字/块进行智能分块 - 图片内容自动调用百炼视觉模型转为文字描述 - 使用 **text-embedding-v4** 模型进行向量化（1536 维） - 写入 **Qdrant** 向量数据库（Cosine 距离度量） - **父子结构存储**：知识块采用「段落（parent）→ 句子（child）」两级结构，批改时先检索句子块，再按段落聚合返回，兼顾精准度和上下文完整性 - **批改时检索**：批改题目时自动对题目文本向量化，搜索 Top-K 相似知识块，按学科过滤 ### 2.3 用户管理 ![image31.png](/data/media/221.png) ![image32.png](/data/media/222.png) - **三种角色**：管理员（Admin）、教师（Teacher）、学生（Student），权限分级 - **JWT 双 Token 认证**：Access Token（120 分钟有效期）+ Refresh Token（7 天有效期） - **自动刷新**：前端 Axios 拦截器在 401 时自动使用 Refresh Token 刷新 - **用户 CRUD**：管理员可增删改查用户，支持启用/禁用账号 - **级联删除**：删除用户时自动清理其所有作业、知识文档和配置 ### 2.4 模型与配置管理 - **模型管理**：管理员可动态管理视觉模型（用于题目识别）和语言模型（用于批改评分）列表 - **个性化配置**：每个用户可独立配置识别模式、视觉模型、批改模型、图像增强开关、知识库开关 - **配置校验**：选择百炼视觉模式时必须指定视觉模型；模型名称必须在系统模型列表中 ### 2.5 数据统计分析 ![image27.png](/data/media/223.png) ![image26.png](/data/media/224.png) - **学习趋势**：基于 ECharts 展示学生成绩变化趋势图 - **多维统计**：按题型统计正确率、按科目分析薄弱环节 - **角色视图**：学生查看个人成绩趋势，管理员查看全局数据 --- ## 3. 系统架构 ![系统功能模块图.png](/data/media/225.png) ### 架构说明 ``` ┌─────────────────────────────────────────────────────────────┐ │ 前端 (Vue 3 + Vite) │ │ 登录 / 注册 / 工作台 / 作业 模型 / 开关） │ ▼ 从 MinIO 下载原图 │ ▼ 图像增强（可选：对比度 1.2x + 锐度 1.1x） │ ▼ ┌─── 多线程 OCR 识别 ───┐ │ │ ├─ 阿里云 OCR ───────────┤ │ cut_paper 切题定位 │ │ → recognize_question │ │ → 保存题目坐标块 │ │ │ ├─ 百炼视觉模型 ─────────┤ │ recognize_question │ │ 端到端多图理解 │ └────────────────────────┘ │ ▼ 保存题目到数据库 │ ▼ ┌─── 多线程 AI 批改 ────┐ │ │ │ 题目文本 → Embedding │ │ → Qdrant 搜索知识块 │ │ → LLM 批改 (Qwen-Plus)│ │ → 输出得分/评语/分析 │ │ │ └────────────────────────┘ │ ▼ 保存批改结果 + 知识引用 │ ▼ Task 状态更新为 completed │ ▼ 学生查看完整批改结果 ``` ### 5.2 知识文档解析流程 ![知识文档解析流程图.png](/data/media/226.png) ``` 教师上传知识文档 (PDF/PPT/Word) │ ▼ 文件存入 MinIO，创建 Knowledge 记录 │ ▼ 投递 Celery 异步任务 knowledge_parse │ ▼ MinerU 上传解析文档 │ ▼ 轮询 MinerU 解析结果（最长 30 分钟） │ ▼ 下载解析结果 ZIP │ ▼ 提取结构化内容（文本 / 表格 / 图片） │ ▼ 处理内容： ├─ 文本 → 分块（≤2000 字/块） ├─ 表格 → 转为文本描述 ├─ 图片 → 百炼视觉模型描述 ├─ 列表 → 拼接为文本 └─ 相邻短文 → 智能合并 │ ▼ 父子结构分块 + Embedding 向量化 │ ▼ 批量写入 Qdrant 向量库 │ ▼ Knowledge 状态更新为 completed ``` ### 5.3 RAG 检索增强批改流程 ``` 题目文本 │ ▼ text-embedding-v4 向量化 (1536 维) │ ▼ Qdrant 相似度搜索 (Cosine 距离) ├─ 阶段一：搜索 child（句子）节点 ├─ 按 parent_id 聚合取最高分 └─ 阶段二：获取 parent（段落）完整内容 │ ▼ 知识片段注入 LLM Prompt │ ▼ Qwen-Plus 批改 → 得分 + 评语 + 解题分析 │ ▼ 保存知识引用关系 (question_chunk 表) ``` --- ## 6. 角色权限体系

4:Tfb3,仓库 [openai/codex: Lightweight coding agent that runs in your terminal](https://github.com/openai/codex) 是 OpenAI 官方推出的轻量级终端 AI 编程助手。与 GitHub Copilot 等闭源产品不同，Codex CLI 完全开源，且允许用户自由切换底层大模型——这意味着你可以接入 DeepSeek 等国产大模型，大幅降低使用成本。

这篇文章将带你走完从安装到实际使用的完整流程。

## 安装 Codex CLI

仓库 README 提供了多种安装方式（Homebrew、WinGet、Docker 等），这里使用 npm 全局安装，最通用也最方便。

```bash
npm install -g @openai/codex
```

如果安装缓慢，可以切换为国内 npm 镜像源：

```bash
npm install -g @openai/codex --registry=https://registry.npmmirror.com
```

安装完成后，在终端运行 codex 验证是否成功：

```bash
codex
```

![image.png](/data/media/698.png)

看到欢迎信息即安装成功。默认情况下 Codex CLI 会使用 OpenAI 的 API，接下来我们配置它接入 DeepSeek。

## 配置 DeepSeek 后端

### 安装 ccx

[ccx](https://github.com/BenedictKing/ccx) 是一个专为 Codex CLI 开发的路由与管理工具，主要解决两个问题：

1. **一键配置**不同的大模型后端（OpenAI、DeepSeek、Anthropic 等）
2. **一键切换**模型配置，无需手动修改 Codex 的配置文件

从 GitHub Releases 页面下载对应系统的安装包，安装后启动即可。ccx 提供图形化界面，操作直观。

> 如果你的 ccx 版本低于 3.17，可能没有内置 DeepSeek 模板，建议下载最新版。

### 添加 DeepSeek 配置

在 ccx 图形界面中选择 DeepSeek 模板，填入你的 API Key 即可完成配置：

![image.png](/data/media/700.png)

### 启动路由

为什么需要启动路由？Codex CLI 默认使用 OpenAI 的 API 协议格式（包括 tool calling 的 Schema 定义、消息结构、流式响应格式等），而 DeepSeek 的 API 格式与之并不完全兼容。ccx 的 router 本质上是一个协议转换层——它接收 Codex CLI 发出的请求，翻译成 DeepSeek 能理解的格式，再将响应映射回 Codex CLI 期望的结构。在 ccx 界面中启动路由功能即可。

![image.png](/data/media/699.png)

路由启动后，保持 ccx 运行，另开一个终端窗口即可开始使用。

### 对话测试

在新终端中运行 codex 并输入一个问题，验证是否成功接入了 DeepSeek：

```bash
codex
```

![image.png](/data/media/701.png)

如果 DeepSeek 正常返回了回答，说明配置成功。

## 在 IDE 中使用 Codex

除了终端交互模式，Codex CLI 还可以作为 AI 后端接入到你常用的 IDE 中，获得内联代码补全和对话体验。

### VS Code

在 VS Code 扩展市场搜索 **OpenAI ChatGPT**（插件名：openai.chatgpt）并安装。安装完成后，在插件设置中选择你本地运行的 Codex 服务作为后端即可。

![image.png](/data/media/703.png)

### JetBrains（IntelliJ IDEA / PyCharm / WebStorm 等）

在 JetBrains 的插件市场搜索 **CC GUI** 并安装。安装后需要做两处配置：

1. **供应商管理**：添加本地 Codex 配置信息，指向你正在运行的 ccx 路由地址
2. **SDK 依赖管理**：安装 Codex 的 SDK 依赖，使插件能够与本地的 Codex CLI 进程通信

![image.png](/data/media/702.png)

对话时记得在插件界面将模型切换到 **Codex** 模式，而非默认的 OpenAI。

## 总结

通过这套方案，你将获得一个完全开源、模型可自由切换、且本地可控的 AI 编程助手。相比直接使用 ChatGPT 或 Copilot，优势在于：

- **极低成本**：DeepSeek 的 API 定价远低于 OpenAI，非常适合日常开发和实验
- **灵活切换**：ccx 让你可以在不同模型间一键切换，对比效果
- **完全可控**：所有代码和数据都在本地，不依赖闭源服务

推荐组合：**Codex CLI + ccx 路由 + DeepSeek**，这是目前性价比最高的 AI 编程环境之一。

## 一、安装：基于 Docker（推荐）

使用 Docker 安装 openGauss 是最快捷的方式，无需手动处理系统依赖和编译配置。

### 官方文档

参考 openGauss 官方容器化部署文档：
[容器镜像安装 | openGauss文档 | openGauss社区](https://docs.opengauss.org/zh/docs/latest/installation_guide/installing_the_container_image.html)

### Docker Compose 配置

创建 `docker-compose.yml` 文件，内容如下：

```yaml
services:  
  mt-opengauss:  
    image: opengauss/opengauss-server:latest  
    container_name: mt-opengauss  
    privileged: true            # 容器内需要内核参数调整，须提权
    environment:  
      GS_PASSWORD: Gauss@123    # 数据库超级用户 gaussdb 的密码（必填）
      GS_DB: fitarena          # 初始化时自动创建的数据库名
      TZ: Asia/Shanghai        # 时区设置为中国标准时间
    ports:  
      - "25433:5432"           # 宿主机 25433 端口映射到容器 5432
    volumes:  
      - /volume/MilkTea/opengauss/data:/var/lib/opengauss  # 持久化数据目录
```

#### 配置说明

| 配置项 | 说明 |
|--------|------|
| `image` | 使用 openGauss 官方最新镜像 |
| `privileged` | openGauss 需要调整内核参数（如共享内存），必须开启提权模式 |
| `GS_PASSWORD` | 必填环境变量，设置数据库超级用户 `gaussdb` 的密码 |
| `GS_DB` | 可选，容器启动时自动创建的数据库名称 |
| `ports` | 容器内部 openGauss 默认端口为 `5432`，映射到宿主机 `25433` |
| `volumes` | 将数据持久化到宿主机，防止容器删除后数据丢失 |

启动容器：

```bash
docker compose up -d
```

## 二、数据库连接方式

### 1. 容器内连接

直接进入容器，使用 `gsql` 命令行工具连接数据库：

```bash
# 进入容器
docker exec -it mt-opengauss bash

# 切换为操作系统超级用户 omm
su - omm

# 使用 gsql 连接数据库（默认端口 5432）
gsql -d postgres -p 5432
```

连接成功后的输出如下：

![image.png](/data/media/581.png)

> **提示：** `-d postgres` 表示连接到 postgres 数据库（openGauss 默认自带的系统数据库），`-p 5432` 指定容器内部端口。

---

### 2. 宿主机连接（使用 psql）

openGauss 兼容 PostgreSQL 协议，因此可以直接使用 `psql` 客户端连接。

#### 安装 psql 客户端

```bash
sudo apt update
sudo apt install -y postgresql-client
```

#### 连接命令

```bash
PGPASSWORD="Gauss@123" psql -h localhost -p 25433 -U gaussdb -d postgres
```

| 参数 | 说明 |
|------|------|
| `PGPASSWORD` | 环境变量方式传入密码（避免交互输入） |
| `-h localhost` | 宿主机地址 |
| `-p 25433` | 映射到宿主机的端口 |
| `-U gaussdb` | openGauss 默认的数据库超级用户名 |
| `-d postgres` | 要连接的数据库名称 |

连接成功输出如下：

![image.png](/data/media/582.png)

---

### 3. IntelliJ IDEA 连接

IDEA 默认不支持 openGauss，需要手动添加 JDBC 驱动。

#### 3.1 下载 openGauss JDBC 驱动

访问 openGauss 官方下载页面，获取最新的 JDBC 驱动 JAR 包：
[openGauss软件 | openGauss下载 | openGauss软件包 | openGauss社区官网](https://opengauss.org/zh/download/)

![image.png](/data/media/578.png)

#### 3.2 在 IDEA 中添加驱动

打开 **Database** 工具窗口（View → Tool Windows → Database），点击 **+ → Driver → PostgreSQL**（因为 openGauss 兼容 PG 协议，选择 PG 模板修改更方便）：

![image.png](/data/media/579.png)

在驱动设置页面：
1. 添加下载好的 openGauss JDBC JAR 包
2. 将 **Class** 设置为 `org.opengauss.Driver`

![image.png](/data/media/580.png)

#### 3.3 创建数据库连接

添加新数据源，填写连接信息：

- **Host：** `localhost`
- **Port：** `25433`
- **Database：** `postgres`
- **User：** `gaussdb`
- **Password：** `Gauss@123`
- **JDBC URL：** `jdbc:opengauss://localhost:25433/postgres`

> ⚠️ **注意：** JDBC URL 路径中必须指定数据库名称，这里使用默认的 `postgres` 数据库。如果不指定会连接失败。

![image.png](/data/media/583.png)

点击 **Test Connection** 验证连接成功后即可使用 IDEA 的 Database 工具浏览和管理数据库。

## 三、常用操作示例

连接成功后，可以尝试以下基本操作：

### 查看数据库列表

```sql
\l
```

### 创建数据库和表

```sql
-- 创建数据库
CREATE DATABASE mydb;

-- 切换到 mydb
\c mydb

-- 创建表
CREATE TABLE user_info (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(200),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 插入和查询数据

```sql
-- 插入数据
INSERT INTO user_info (name, email) VALUES ('Alice', 'alice@example.com');
INSERT INTO user_info (name, email) VALUES ('Bob', 'bob@example.com');

-- 查询数据
SELECT * FROM user_info;
```

>注意：IDEA 中数据库操作以连接配置里指定的库为准。即便在图形界面切换了数据库，SQL 仍会在配置库中执行，界面仅做展示更新。

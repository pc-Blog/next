# 后端部署（Docker）

## 构建镜像

```bash
cd d:/Projects/project/Blog/Blog
docker build -t bg-api:latest .
```

## 启动所有服务

```bash
cd d:/Projects/project/Blog/Blog
docker compose -f docker-compose.yml up -d
```

## 更新后端（改代码后）

```bash
cd d:/Projects/project/Blog/Blog
docker build -t bg-api:latest .
docker compose -f docker-compose.yml up -d
```

## 查看日志

```bash
docker logs bg-api -f --tail 50
```

## 验证

```bash
curl -s -X POST http://localhost:18016/api/auth/ping
# → {"code":1,"message":"success","data":"local_only_token"}
```

# 部署前端

## 构建镜像

```bash
cd d:/Projects/project/Blog/next
docker build -t blog-next .
```

## 启动

```bash
cd d:/Projects/project/Blog/Blog
docker compose -f docker-compose.yml up -d
```

> `bg-blog` 和 `bg-api` 在同一个 compose 文件中管理，启动后端时前端也会一起启动。

免费订阅服务升级：MailerLite 完全指南（与 Buttondown 对比）

## 为什么从 Buttondown 迁移到 MailerLite？ 在上一篇文章[我如何用 Buttondown 从零搭建 Newsletter](https://www.lxpavilion.top/article/50/)中，我详细记录了探索 Buttondown 的过程。但在实际评估后，我最终选择了 **MailerLite** 作为博客的 Newsletter 主力方案。 核心原因只有一个：**RSS 自动推送**。 Buttondown 的 RSS 自动推送需要付费（$9/月），而 **MailerLite 免费版就包含 RSS 自动发送**，且同样支持自定义域名发件。对于追求"写完文章自动通知订阅者"的独立博客作者来说，MailerLite 是目前性价比最高的选择。 --- ## 一、Buttondown vs MailerLite 详细对比 | 功能 | Buttondown 免费版 | MailerLite 免费版 | |------|:---:|:---:| | 订阅者上限 | 1,000 | 1,000 | | 每月免费发信量 | 无限（公平使用） | 12,000 封 | | 自动 RSS 推送 | ⚠️ **付费（$9/月）** | ✅ **免费** | | 自定义域名发件 | ✅ 需 DNS 验证 | ✅ 需 DNS 验证 | | 品牌标志 | 无 | 无 | | 邮件自动化序列 | 有限 | 完整（欢迎邮件、工作流） | | API | ✅ 免费 | ✅ 免费 | | 风控稳定性 | 新账户易被风控禁用 | 风控宽松，适合稳定使用 | **结论：** 如果你需要 **全自动 RSS 推送** 且不想付费，MailerLite 是更优选择。这也是我最终选择它的决定性因素。 > 如果你还在纠结选哪个，可以这样判断： > - 在意 **极简写作界面 + 无品牌标志** → Buttondown（RSS 付费） > - 需要 **RSS 免费自动推送 + 自动化工作流** → MailerLite ✅ --- ## 二、注册与基础设置 ### 1. 注册账号 打开 [MailerLite 官网](https://www.mailerlite.com/) → 点击 **Sign Up Free**，用邮箱注册即可（无需信用卡）。 ![image.png](/data/media/488.png) 完成注册流程后进入控制台主页： ![image.png](/data/media/489.png) ### 2. 配置发件人信息 在控制台中配置发件人姓名和邮箱。注意：如果使用自定义域名邮箱，需要先完成域名验证（见下一步）。 ![image.png](/data/media/493.png) --- ## 三、配置自定义域名（关键步骤） ### DNS 验证 在 **Account Settings → Domains** 页面配置你的域名。如果看到已有域名但未认证，可以删除后重新添加，系统会自动弹出认证流程。 ![image.png](/data/media/492.png) ### Cloudflare 一键授权 MailerLite 对 Cloudflare 域名提供了 **简化配置流程**——点击对应按钮后，会自动跳转到 Cloudflare 授权页面，授权后 DNS 记录自动添加，省去手动配置的麻烦。 ![image.png](/data/media/491.png) 如果你使用其他 DNS 服务商，MailerLite 也会给出需要手动添加的 DNS 记录（包括 SPF、DKIM、MX 等），按提示在 DNS 管理面板添加即可。 --- ## 四、创建订阅组与嵌入表单 MailerLite 通过 **Groups（组）** 来管理订阅者分类，非常灵活。 ### 1. 创建分组 在 **Subscribers → Groups** 模块中创建分组。例如，按内容主题创建"技术教程""读书笔记"等组，方便后续针对不同组发送不同的 Newsletter。 ![image.png](/data/media/494.png) ### 2. 创建订阅表单 MailerLite 提供三种表单类型： | 类型 | 说明 | 适用场景 | |------|------|---------| | **Embedded（嵌入式）** | 嵌入到网页中 | ✅ 博客侧边栏 / 文章末尾 | | **Popup（弹窗式）** | 进入页面时弹出 | 高转化率但可能影响体验 | | **Landing Page（落地页）** | 独立的订阅页面 | 专门推广链接 | 我使用的是 **嵌入式表单**，直接嵌入到博客页面中。 ![image.png](/data/media/495.png) ### 3. 选择分组并设计表单 选择表单对应的分组，这样通过该表单订阅的读者会自动归类到该组： ![image.png](/data/media/496.png) 点击继续进入编辑页面，可以自定义表单的外观、字段和样式，编辑完成后系统会自动生成对应的 HTML、CSS 和 JavaScript 代码。 ![image.png](/data/media/497.png) ### 4. 获取嵌入代码并测试 点击完成后会生成完整的嵌入代码。右侧也提供了测试 URL，可以先点击测试，验证订阅功能是否正常工作。 ![image.png](/data/media/498.png) ### 5. 测试订阅流程 读者提交邮箱后会收到确认邮件（Double Opt-in），点击确认即可激活订阅。免费版也支持 Double opt-in，确保订阅者真实有效，同时也是合规要求。 下面是测试截图，可以看到已经有一个订阅者了： ![image.png](/data/media/499.png) ![image.png](/data/media/500.png) --- ## 五、配置 RSS 自动推送（免费核心功能） 这是 MailerLite 相比 Buttondown 最大的优势——**免费版原生支持 RSS 自动转邮件**。 ### 操作步骤 1. 进入 **Campaigns** 页面，点击创建新 Campaign 2. 选择 **RSS campaign**（RSS 活动）类型 3. 依次配置： - **目标分组**：选择要发送给哪个组的订阅者 - **发送周期**：可选择每次 RSS 更新时发送，或按天/周汇总发送 - **RSS Feed URL**：输入你博客的 RSS 地址 - **邮件模板**：选择或自定义邮件样式 ![image.png](/data/media/503.png) ### 发送频率建议 | 博客更新频率 | 推荐 RSS 推送策略 | |-------------|-----------------| | 每天更新 | 按天汇总，每天发一封摘要 | | 每周 2-3 篇 | 每次更新立即发送 | | 每周 1 篇 | 每次更新立即发送 | | 不定期 | 每次更新立即发送 | ### 测试验证 配置完成后，可以使用测试发送功能，验证 RSS 是否能正确抓取并渲染成邮件： ![image.png](/data/media/502.png) 收到测试邮件后，检查邮件排版、链接和退订功能是否正常： ![image.png](/data/media/504.png) --- ## 六、踩坑记录 在配置过程中也遇到了一些小问题，记录下来供参考： ### 1. 域名验证延迟 即使 Cloudflare 一键授权成功，MailerLite 的域名状态可能需要几分钟才能更新为已验证。耐心等待即可，无需重复操作。 ### 2. Double Opt-in 邮件未收到 如果测试订阅时没有收到确认邮件，检查： - 垃圾邮件文件夹 - 域名 DKIM/SPF 记录是否配置正确 - 发件人邮箱是否已验证 ### 3. 表单样式兼容性 MailerLite 生成的嵌入式表单代码包含 CSS，在部分主题中可能存在样式冲突。建议在嵌入后检查一下移动端显示效果。 --- ## 七、运营建议 ### 善用欢迎邮件 MailerLite 支持设置自动化欢迎邮件序列——新订阅者确认后自动收到一封介绍邮件，这是建立读者关系的第一步。 ### 分组精细化运营 不要把所有读者放在一个组里。建议： - 根据博客内容主题创建多个组 - 不同的 RSS Campaign 推送给不同的组 - 后续可以针对活跃/不活跃订阅者做区分运营 ### 关注数据指标 MailerLite 提供详细的数据分析： - **打开率**：目标 25%+ - **点击率**：目标 3%+ - **退订率**：控制在 0.5% 以下 如果打开率持续偏低，尝试优化邮件标题；如果退订率上升，检查发送频率是否过高。 --- ## 总结 MailerLite 免费版完美覆盖了 Buttondown 的几乎所有功能，且 **RSS 自动推送免费**，API 稳定，更适合长期使用。 | 维度 | 评价 | |------|------| | 学习成本 | ⭐⭐⭐⭐⭐ 很低，界面直观 | | 核心功能 | ⭐⭐⭐⭐⭐ RSS 免费推送是杀手级功能 | | 自定义性 | ⭐⭐⭐⭐ 模板和表单足够灵活 | | 稳定性 | ⭐⭐⭐⭐⭐ MailerLite 是老牌平台，风控宽松 | | 性价比 | ⭐⭐⭐⭐⭐ 免费版已满足个人博客全部需求 | 按本文配置完毕后，你只需专心写文章，新内容会自动送达订阅者。 **相关阅读：** - [我如何用 Buttondown 从零搭建 Newsletter](https://www.lxpavilion.top/article/50/) — 探索过程记录 - [选择 Cloudflare，给我的博客带来了什么](https://www.lxpavilion.top/article/49/) — 博客底层基础设施 如果你在配置过程中遇到问题，欢迎交流。🚀

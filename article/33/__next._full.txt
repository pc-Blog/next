## 三、配置 CCX

CCX 作为 API 代理，负责将 Codex 的请求转发到 DeepSeek 等服务。

### 3.1 安装 CCX

在 [CCX 官方文档](https://github.com/BenedictKing/ccx) 仓库找到对应版本的包下载。

我下载的是**CCX-Desktop-2.8.4-windows-amd64-setup.exe**

### 3.2 添加渠道

1. 打开 CCX 管理界面，切换到 **Codex** 页面。
2. 填入 **URL（https://api.deepseek.com）** 和 **API Key**，然后点击「详细配置」。
3. 在详细配置中：
   - 将**服务类型**改为 **OpenAI Chat**
   - 开启**规范化 metadata.user_id** 选项
4. 点击「创建渠道」完成添加。

![6.png](/data/media/38.png)

---

## 四、配置 CCSwitch

CCSwitch 用于统一管理和切换不同的 AI CLI 工具。

1. 打开 CCSwitch，切换到 **OpenAI** 界面。
2. 点击「添加供应商」，选择 **自定义**。
3. 填入以下信息：
   - **地址**：CCX 的地址
   - **API Key**： API Key
4. 点击「获取模型列表」。
   - 如果能正常加载模型列表，说明配置正确。
5. 点击「保存」完成配置。

![5.png](/data/media/39.png)

![2.png](/data/media/34.png)

---

## 五、进入 Codex

1. 启动 Codex。
2. 在登录方式中选择 **使用 API 登录**。
3. 输入ccx的 API 信息，即可开始使用。

![3.png](/data/media/35.png)

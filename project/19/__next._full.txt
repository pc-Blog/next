## 简介

**PlaneWar** 是一款经典的竖版飞行射击游戏，玩家操控英雄战机，在无尽的敌机浪潮中生存并击败强大的 Boss。相比传统的飞机大战，这个版本在玩法丰富度上做了大量扩展——6 种武器系统、11 种 Boss 攻击模式、多种敌机类型，以及丰富的道具系统。

---

## 游戏玩法

### 战机操控

| 操作 | 功能 |
|------|------|
| WASD | 八方向移动（含 Q/E 斜向） |
| 空格 | 射击（配合 1/2/3 切换武器） |
| 左 Shift | 发射导弹 |
| 鼠标左键 | 激光 |
| 鼠标右键 | 核弹 |
| 鼠标滚轮 | 切换激光颜色 |
| B | 显示敌我血量 |
| P | 暂停 |
| C | 慢动作 |

### 武器系统

游戏提供了丰富的武器选择：

1. **普通子弹** — 基础武器，稳定输出
2. **加特林** — 高射速，火力压制
3. **追踪弹** — 自动追踪敌人，智能打击
4. **导弹** — 延迟后追踪鼠标位置，高伤害
5. **激光** — 持续光束，7 种颜色可切换
6. **核弹** — 全屏清场，终极手段

### 敌机种类

| 敌机 | 特点 |
|------|------|

## 技术实现

### 架构概览

项目采用模块化设计，核心文件结构如下：

```
plane_main.py              # 主循环、碰撞检测、事件处理
plane_sprites/
├── base.py                # GameSprite 基类
├── hero.py                # 英雄、子弹、导弹、激光、爆炸
├── enemies.py             # 5 种敌机 + 2 种子弹
├── boss.py                # Boss + 11 种攻击
├── items.py               # 道具掉落、HUD
├── ui.py                  # 菜单界面
├── constants.py           # 常量、图片缓存工具
└── game_config.py         # 数值配置
images/                    # 分类图片资源
music/                     # 音效资源
```

### 八方向系统

游戏使用预定义的 8 个角度方向（0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°），通过 `get_dir_images()` 函数在加载时预旋转并缓存所有方向的图片，避免每帧进行昂贵的 `pygame.transform.rotate()` 调用。

```python
DIRECTION_ANGLES = {0: 0, 1: 180, 2: 90, 3: 270,
                    4: 45, 5: 315, 6: 135, 7: 225}
```

### 图片优化

- **目录重组** — 200+ 张散落图片按类别归入 9 个子目录
- **激光压缩** — 28 张彩色激光 PNG 缩减为 4 张白底基图，运行时通过 `BLEND_RGB_MULT` 染色，缩减 85%
- **冗余清理** — 删除了 73 张未引用图片（英雄八方向预旋转变体、Boss 毁灭帧等）
- **类级缓存** — 爆炸帧、受击帧通过类级懒加载共享，避免重复磁盘 I/O
- **旋转缓存** — `get_dir_images()` 预旋转并缓存多方向图片

### 碰撞检测

游戏采用双层碰撞检测：
1. **AABB 包围盒预检** — 快速淘汰远离的物体对
2. **像素级遮罩碰撞** — `pygame.sprite.collide_mask` 精确到像素

36 个精灵组之间形成 19×6 的碰撞检测网格，确保所有交互（子弹击中敌机、道具拾取、护盾反弹等）都被正确处理。

### 动画与特效

- 敌机毁灭 4 帧逐帧动画
- 英雄 2 帧呼吸动画
- Boss 2 帧浮动动画
- 爆炸效果 28 帧动画
- 导弹 4 帧旋转动画
- 激光分段光束效果

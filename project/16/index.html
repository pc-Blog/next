万象阁

基于 Spring Boot 3 + Kotlin + MyBatis-Plus 后端与 Vue 3 + TypeScript + Vite 前端的全栈个人工具集。集成日记记录、文章管理、阅读笔记、单词库、音乐播放、AI 阅读器等模块，为个人知识管理与日常效率提升提供一体化解决方案。

项目概览

OmniPavilion（万象阁）是一个面向个人使用的多功能工具集，采用前后端分离架构，涵盖写作记录、知识管理、语言学习、影音娱乐四大场景。项目深度集成了 Spring AI 框架与大语言模型（LLM），在文章阅读、文档问答、词汇学习等模块中实现了 AI 驱动的智能交互体验。

功能模块详解

1. 日记本（Diary）—— 生活记录与时间管理

一套完整的个人日记系统，支持三种记录维度。

每日日志：以"天"为单位记录生活，包含天气标记（晴/多云/阴/雨/雪等 8 种）和多条活动条目（支持学习、工作、生活、运动、娱乐、社交 6 种分类）。日志按年-月分组展示，支持日期范围筛选和分类过滤。

待办事项（Notes）：支持创建带截止日期和时间的待办事项，状态流转（草稿 → 待办 → 进行中 → 已完成 → 已取消 → 已过期）。自动检测已过期的待办项，到期提醒会在进入页面时主动推送。

计划追踪（Plans）：创建跨时间段的计划并拆解为多个子任务，每个子任务可独立跟踪状态。首页自动汇总进行中的计划数量，计划详情中展示时间进度条与任务完成率。

后端模块：diary（Gradle 子项目），4 张数据表（daily_time、daily_activity、note、plan、t_plan_task）。

前端模块：Vue3/src/diary，独立 SPA 入口，4 种主题可切换（classic / modern / dark / vintage）。

2. 文集（Article）—— Markdown 文章创作与 AI 阅读

以 Markdown 为核心的文章管理系统，结合 AI 实现智能阅读辅助。

文章管理：创建、编辑、删除文章，文章正文以 .md 格式存储在 MinIO 对象存储中。支持按标题模糊搜索、按标签筛选、按日期范围过滤。文章列表以年-月时间轴形式展示。

Markdown 编辑器：内置实时预览的 Markdown 编辑器，支持 Ctrl+S 快捷键保存，状态栏实时显示字数统计、写作日期与天气。文章可单独下载为 .md 文件，也可一键批量打包下载为 ZIP。

AI 文章阅读：选中文章后，AI 助手（基于阿里云通义千问 Qwen 大模型）以文章全文为上下文，支持自由提问。对话历史按文章维度独立存储并持久化到 MySQL，支持导出为 Markdown 聊天记录。

后端模块：article（Gradle 子项目），3 张数据表（t_article、t_tag、t_article_tag），集成 Spring AI ChatClient + MessageChatMemoryAdvisor + 自定义 ArticleAdvisor。

前端模块：Vue3/src/article，独立 SPA 入口，复古笔记本风格 UI，三栏可折叠布局。

3. AI 阅读器（Bibliophile）—— 文档上传与智能问答

一个基于 RAG（检索增强生成）技术的智能文档阅读系统。

文件上传：支持上传 PDF、Word（DOC/DOCX）、Excel（XLSX/CSV）、纯文本（TXT）、Markdown（MD）等 7 种格式的文档，文件存储至 MinIO。上传后自动解析文件内容并建立向量索引。

智能问答：用户可针对上传的文档进行自由提问，系统通过向量相似度检索（topK=5，相似度阈值 0.3）召回相关段落，结合大模型生成回答。回答以 SSE 流式输出，打字机效果实时展示。

聊天管理：对话历史按文档维度独立存储，支持查看历史消息、逐条删除、清空会话、导出为 Markdown。应用启动时自动清理向量存储，每小时定时清理以释放内存。

后端模块：bibliophile（Gradle 子项目），1 张业务表（t_ai_reader_file）+ Spring AI 聊天记忆表（spring_ai_chat_memory），集成 OpenAiEmbeddingModel + SimpleVectorStore + QuestionAnswerAdvisor。

前端模块：Vue3/src/bibliophile，独立 SPA 入口，深色/浅色主题，浮动书籍动画背景。

4. 英文词汇（English）—— WordNet 语义网络与智能记词

一个深度整合 WordNet 离线词典与 AI 辅助的英语词汇学习平台。

WordNet 语义探索：基于 Princeton WordNet 3.1 词汇数据库，通过 extJWNL 离线查询单词的完整语义关系网络——释义、同义词、反义词、上位词、下位词、整体词、部分词、惯用语。支持按词性（名词/

基础单词库：预置单词库，按分类检索，支持中英文模糊搜索。 动词/形容词/副词）筛选浏览全部词汇。

个人词汇本：完整的 CRUD 操作，每个单词包含多种词性释义、例句及翻译。支持学习状态流转（默认 → 重点 → 已学习），批量删除，随机测验。

AI 智能助手：集成 AI 对话式查词与加词功能。用户可以输入单词，AI 自动返回详细释义、音标、例句，用户确认后可一键添加到个人词汇本。AI 助手以可拖拽浮动窗口形式存在，不影响主界面操作。

后端模块：english（Gradle 子项目），7 张业务表（基础词库 t_word/t_category/t_word_category；详细词汇 t_vocabulary/t_definition/t_sentence/t_part_of_speech/t_status），集成 extJWNL + Spring AI Tool Calling（AI 自动调用加词工具）。

前端模块：Vue3/src/english，独立 SPA 入口，蓝色主题，天气动画（晴天/阴天/雨天/雷电/下雪/刮风），动态云朵和旋转 Logo。

5. 音乐播放器（Music）—— 个人音乐库管理与播放

一个功能完备的 Web 音乐播放器。

音乐管理：支持 MP3、FLAC、WAV、AAC、OGG、M4A 格式的批量上传，自动提取音频时长。按歌手和分类（流派）组织音乐库，支持收藏与播放计数。文件存储于 MinIO，按歌手文件夹组织。

播放控制：支持顺序播放、随机播放、单曲循环三种模式。播放器状态（当前曲目、音量、播放模式、累计播放时长）持久化至 Redis，跨会话保持。进度条支持拖拽跳转，播放超过 80% 后自动计数。

数据完整性：内置音频文件完整性校验功能，扫描 MinIO 存储与数据库记录的一致性，检测孤立文件与缺失文件。

歌手与图片管理：歌手支持增删改查，每位歌手可上传多张图片，随机选取作为播放器封面。删除歌手时自动将其歌曲迁移至默认分类。

后端模块：music（Gradle 子项目），4 张数据表（music、singer、category、singer_picture），播放状态存储于 Redis Hash。

前端模块：Vue3/src/music，独立 SPA 入口，毛玻璃霓虹主题，Canvas 外星景观动画背景，可拖拽浮动播放器组件。

项目架构

后端架构

SpringBoot/
├── common/          # 共享基础设施
│   ├── config/      # MyBatis-Plus分页、CORS、拦截器、定时任务、MinIO客户端
│   ├── exception/   # 全局异常处理（BusinessException → 统一JSON错误响应）
│   ├── utils/       # MinIO工具、文件解析（7种格式→Spring AI Document）、文件操作
│   ├── pojo/        # 通用DTO/VO（PageDTO、PageVO、Result）
│   └── service/     # AI聊天记忆服务（CRUD + Markdown导出）
├── diary/           # 日记模块（日志/待办/计划）
├── article/         # 文章管理模块（CRUD + AI阅读）
├── bibliophile/     # AI阅读器模块（文档上传 + RAG问答）
├── english/         # 英语词汇模块（WordNet + AI查词）
└── music/           # 音乐播放器模块（文件管理 + 播放状态）

每个业务模块均为独立的 Gradle 子项目，可单独打包为 JAR/WAR，依赖 common 模块提供的基础能力。

前端架构

Vue3/src/
├── application/     # 主入口 + 首页导航
├── common/          # 共享资源（Axios/Fetch封装、通用类型、日志工具、404页面）
├── diary/           # 日记本（复古主题，路由导航）
├── article/         # 文集（三栏布局，SSE流式AI聊天）
├── bibliophile/     # AI阅读器（状态驱动的视图切换）
├── english/         # 英语词汇（路由导航，浮动AI助手）
├── music/           # 音乐播放器（Canvas动画，拖拽播放器）
├── noFound/         # 404页面
└── template/        # 基础页面模板

每个功能模块均为独立的 SPA 入口（各自的 index.html），Vite 自动发现并构建多页面应用。模块间通过首页导航卡片关联，当前以新标签页形式跳转。

数据层

  • MySQL：业务数据持久化，每个模块使用独立数据库（diary、article、bibliophile、english、music）
  • Redis：音乐播放器状态、缓存
  • MinIO：文章 Markdown 文件、上传文档、音频文件、歌手图片

AI 集成亮点

OmniPavilion 深度集成了 Spring AI 框架，借力大语言模型实现多个智能场景：

模块AI 能力技术实现
文集（Article）文章上下文智能问答ChatClient + MessageChatMemoryAdvisor + 自定义 Advisor 注入全文
AI 阅读器（Bibliophile）文档 RAG 问答OpenAiEmbeddingModel + SimpleVectorStore + QuestionAnswerAdvisor（topK=5）
英语词汇（English）智能查词与一键加词ChatClient + Tool Calling（AI 自动调用 addWord 函数写入数据库）

所有 AI 对话均支持：

  • SSE 流式输出（打字机效果）
  • 对话历史持久化（MySQL spring_ai_chat_memory 表）
  • 聊天记录导出为 Markdown 文件
  • 按维度隔离的对话上下文（文章/文档独立会话）

特色设计

多主题 UI：日记模块提供 4 种主题（classic / modern / dark / vintage），AI 阅读器支持深色/浅色切换，音乐模块采用毛玻璃霓虹风格，词汇模块融入实时天气动画。

动态服务器发现：前端启动时自动探测可用后端服务器（远程服务器 → 局域网 → 本地），无需手动配置 API 地址。

文件完整性校验：音乐模块内置数据完整性审计，可一键交叉校验 MinIO 文件与数据库记录的一致性。

WordNet 离线语义网络：英语词汇模块内置 Princeton WordNet 3.1 词典，无网络环境下仍可查询单词的完整语义关系（同义词、反义词、上下位词、整体部分词、惯用语等）。

模块化打包：每个后端模块可独立构建和部署（JAR/WAR），前端每个模块为独立 SPA 入口，Vite 自动构建多页面应用。

快速开始

环境要求

  • JDK 21
  • Kotlin 2.1
  • Node.js 18+
  • MySQL 8.0+
  • Redis 7.0+
  • MinIO（对象存储）

后端启动

# 克隆项目
git clone <repository-url>
cd OmniPavilion/SpringBoot

# 配置数据库连接，编辑 common/src/main/resources/args-dev.yaml
# 启动全部模块
./gradlew bootRun

# 或单独启动某个模块
./gradlew :diary:bootRun
./gradlew :article:bootRun
./gradlew :bibliophile:bootRun
./gradlew :english:bootRun
./gradlew :music:bootRun

前端启动

cd OmniPavilion/Vue3

# 安装依赖
npm install

# 启动开发服务器（默认80端口，多页面自动发现）
npm run dev

# 构建生产版本
npm run build
